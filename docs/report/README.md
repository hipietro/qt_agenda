# Final report

This directory contains the version-controlled source of the final standalone project report:

- `Relazione_Agenda_Qt_Acampora.md`: reviewable report content;
- `../uml/README.md`: updated UML and architecture diagrams.

The final DOCX and PDF are generated deliverables used for the submission package rather than source-code inputs. The report is written as a complete first-reading description of the delivered project. It does not require access to an older report. The mandatory `Modifiche rispetto alla consegna precedente` section records changes to the project itself because it is required for resubmissions.

The report contains:

- student name and number;
- introduction and detailed requirement-compliance evidence;
- logical-model classes and responsibility separation;
- updated UML diagrams;
- explicit analysis of Visitor and Command polymorphism;
- explanation of the remaining justified `ActivityKind` uses;
- JSON persistence architecture and factory registry;
- in-window creation and editing workflows;
- detailed optional features, including normalized/fuzzy search, filters, categories, recurrence, templates, monthly overview and undo/redo;
- automated testing, robustness and efficiency notes;
- hour accounting;
- the mandatory project-change section;
- build instructions and conclusion.

Validation performed during authoring:

- A4 layout;
- 10 pt body text;
- 8 pages;
- dense layout with controlled whitespace;
- visual render review of every page;
- no clipped text, overlapping elements or broken figures.
