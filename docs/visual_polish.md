# Visual polish

This refinement pass improves presentation without changing the application's workflows:

- visible resizable splitters between navigation, details, and monthly overview;
- a quieter neutral palette with one primary accent;
- compact action buttons with consistent SVG icons;
- corrected month navigation controls and unclipped Today button;
- a search affordance and clear-button support;
- type-specific icons in Visitor-built activity cards;
- preserved keyboard shortcuts, mouse interactions, and responsive in-window navigation.
